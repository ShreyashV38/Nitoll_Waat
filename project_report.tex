\section*{2. Topic of the Mini Project}
%------------------------------------------------------------

\textbf{NitollWaat} is a Smart Waste Management System built for urban
municipalities in Goa. It provides real-time bin monitoring, automated
collection route management, and a public citizen complaint portal ---
accessible through both an Admin Web Dashboard and a Driver Mobile
Application.

\clearpage
%------------------------------------------------------------
\section*{3. Objective of the Mini Project}
%------------------------------------------------------------

\begin{enumerate}[leftmargin=*, label=\arabic*.]
    \item Monitor waste bin fill levels in real time across all wards.
    \item Assign optimised collection routes to garbage truck drivers.
    \item Allow citizens to view bin status and submit complaints without login.
    \item Track garbage vehicles and record trip history for the admin.
    \item Provide analytics and reports to aid municipal decision-making.
\end{enumerate}

%------------------------------------------------------------
\section*{4. Features of the Website}
%------------------------------------------------------------

\begin{itemize}[leftmargin=*]
    \item \textbf{Live Bin Map} -- Interactive map showing colour-coded
          bin markers (green/amber/red) for a selected area in Goa.
    \item \textbf{Citizen Complaint Portal} -- Residents can click a bin
          on the map and report issues (overflow, damaged lid, etc.)
          without creating an account, in multiple regional languages.
    \item \textbf{Admin Dashboard} -- KPI cards showing total bins,
          active vehicles, unresolved complaints, and collection trends.
    \item \textbf{Route Management} -- Create and assign collection routes
          to drivers; drivers see their route on the mobile app.
    \item \textbf{Fleet \& Vehicle Tracking} -- Register vehicles, track
          their location, and view trip history.
    \item \textbf{Messaging} -- Admin can broadcast messages/alerts to
          drivers via the web app.
    \item \textbf{Role-based Access} -- Separate logins for Admin and
          Driver with protected routes.
\end{itemize}
